# Электронная аттестация ПД

Сайт для аттестации сотрудников Полицейского Департамента ранга «Рядовой» на игровом RP-сервере Minecraft.

Сотрудник вводит игровой ник и отвечает в свободной форме на 15 вопросов. Сайт сам сравнивает ответы с ключами, начисляет баллы и показывает итог, который удобно отправить руководству скриншотом. Аттестация сдана, если не менее 10 вопросов получили полный балл. После неуспешной попытки следующая доступна через 45 минут (срок задаётся константой `RETAKE_LOCK_MINUTES` в [src/storage/storage.ts](src/storage/storage.ts)).

Серверной части нет: сайт статический, все данные хранятся только в браузере сотрудника и никуда не отправляются.
